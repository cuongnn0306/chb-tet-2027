## Implemented

- src/lib/report-xlsx-export.ts: generic buildXlsxExport engine (pinned @excel.js/exceljs 0.15.0). Serializes exactly the caller-supplied, already-authorized, already-filtered rows using explicit Vietnamese-header column definitions (text | vnd | integer) and writes a second 'Bộ lọc' sheet with the caller's filter snapshot, row count and optional export-time label. No data fetching, no date/location/user/channel policy, no KPI computation.
- Validation before building: unique column keys and headers (two measures cannot share a header), safe-integer-only VND/integer cells (rejects floats, NaN, Infinity, > 2^53-1, strings) with row/column named in the Vietnamese error, required keys with null as blank, Excel limits (1,048,575 data rows, 16,384 columns, 32,767 chars/cell, sheet-name rules), XML-invalid control characters removed.
- Formula-injection guard for cells, headers and filter snapshot: values starting with = + - @ tab or CR (also after leading whitespace/control chars) are stored with a leading apostrophe.
- Output: Uint8Array xlsx, MIME type, row count and an ASCII-safe filename (diacritics folded, unsafe characters and Windows reserved names handled, length bounded).
- docs/exec-plans/active/RPT-012-xlsx-export.md records contract, decisions and the acceptance limits not met by this engine-only task.
