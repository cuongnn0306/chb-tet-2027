## Procedure

- Merge each lane with `--no-ff` and keep the lane's own commits and reports. Conflicts are expected only in `docs/handoff/tasks.json` and `docs/handoff/STATUS.md`: take the semantic union per task ID (a record changed on only one side wins; a record changed differently on both sides stops the merge for inspection) and regenerate STATUS with the pipeline's index rule. A `git merge-tree` simulation on 19/10 found no source conflicts in any Wave A lane or in INF-008.
- `git diff --check` before each merge commit; `package-lock.json` is regenerated by one `npm install` at the end of the wave that changes dependencies.
- Each wave ends with `task:finish` (shared DB lease, `db reset`, pgTAP, integration). A hand pre-run of the DB checks before `task:finish` is allowed and is disclosed in the summary.
